# Ropixon LoRa Gateway

Experimental local Home Assistant OS app, aarch64 / amd64. Controls a Ropixon
AT-LoRa USB dongle and publishes devices through MQTT Discovery. The current
version supports one gateway with up to 256 sensors, temperature, voltage,
pairing and removal of sensors.

Guide: [DOCS.md](DOCS.md). Requires a working MQTT broker and HA MQTT integration.
First installation on actual HA OS still awaits verification. No dongle firmware change.
