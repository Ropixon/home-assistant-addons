# Home Assistant add-ons by Ropixon

Home Assistant add-ons by Ropixon – RopixNet LoRa gateway and more.

## Installation

1. In Home Assistant open **Settings → Add-ons / Apps → Store**.
2. **⋮ → Repositories**, add `https://github.com/Ropixon/home-assistant-addons` and close the dialog.
3. Open the add-on (for example **Ropixon LoRa Gateway**) and press **Install**.

Home Assistant downloads a prebuilt image (64-bit `aarch64`, e.g. Raspberry Pi
3/4/5 with 64-bit Home Assistant OS, or `amd64`); nothing is compiled on the
device. Updates appear in the same place.
